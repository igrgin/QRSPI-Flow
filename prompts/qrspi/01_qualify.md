# Q Phase — Qualify Prompt

We are working on the issue in `issue.md`.

Your task is to QUALIFY the work before any research or implementation.

Output format:
1. Problem restatement (1-2 paragraphs)
2. In-scope / out-of-scope bullets
3. Assumptions and unknowns
4. Clarifying questions (if any)
5. Acceptance criteria (explicit, testable)
6. Suggested decomposition into sub-problems

Rules:
- Do not perform implementation.
- Do not provide code changes.
- Be explicit about uncertainty.
