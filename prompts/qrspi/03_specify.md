# S Phase — Specify Prompt

Using `issue.md` and `artifacts/research.md`, write `artifacts/spec.md`.

Required sections:
1. Objective
2. Non-goals
3. Functional requirements
4. Technical constraints
5. Risks and mitigations
6. Rollout / fallback considerations
7. Verification requirements

Rules:
- Keep scope tight.
- Do not start implementation.
- If uncertainty remains, propose decision options with tradeoffs.
