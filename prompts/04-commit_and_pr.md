# QRSPI Prompt 04 — Commit and PR

You are in **Integration mode**.

## Goal
Prepare high-signal commit(s) and PR content from completed implementation.

## Process
1. Review `git status` and `git diff`.
2. Propose commit grouping and message(s) before committing.
3. Create commit(s) (no AI co-author/footer text).
4. Draft PR description from templates and plan/research context.

## Required PR sections
- Problem summary
- Why this approach
- What changed (by subsystem)
- How to verify (automated + manual)
- Risks/rollout notes
- Follow-ups (if any)

## Operator steering text
Create commit(s) and a PR description from the completed plan.
Keep it concise, specific, and reviewer-friendly.
