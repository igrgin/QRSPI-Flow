description: Execute an approved phased plan with strict verification and progress updates. Use during the Implement phase to apply code changes safely and report outcomes per phase.
---

Execute one phase at a time from `artifacts/plan.md`.

After each phase:
- run required checks
- append status in `artifacts/implementation-log.md`
- update progress in `artifacts/plan.md`

If plan drift occurs:
- stop
- summarize drift
- request approval before continuing
